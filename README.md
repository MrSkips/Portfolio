# Zackery Pierce | Mechanical Engineering Portfolio

Static portfolio website with project galleries, a casting video, and one resume download.

## Upload to GitHub

1. Extract this ZIP on your computer.
2. Upload the extracted contents to your repository. Keep index.html, style.css, script.js, and the assets folder together at the repository root.
3. Enable GitHub Pages for that repository, using the main branch and root folder as the publishing source.

Upload the extracted files, not the ZIP itself. No installation or build step is needed.

## Local preview

Open index.html in a browser, or serve this folder with a static HTTP server.

## Editing

- index.html: portfolio content and structure
- style.css: appearance and responsive layout
- script.js: galleries and media dialogs
- assets/: photos, video, project poster, supplied course drawing, and resume PDF

Google Fonts is used for typography, with local font fallbacks.
The resume and project materials are served publicly when GitHub Pages is enabled.
